Privacy policy

Last updated: 21 September 2026

yt-arhiva is a personal tool used only by its owner. It is not a public service and has no other users.

What data it accesses

  • Through the YouTube Data API, with the owner's consent, it uploads the owner's own video files to the owner's own YouTube channel as private videos, and creates playlists, thumbnails and captions for them.
  • It does not read, collect or analyse any other data from the Google account.

Where data is stored

  • The OAuth token is stored only on the owner's own home server and is never shared.
  • No data is sent to any third party, sold, or used for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy.
